# 0053 ポリシーへのリンクは、＋の追加ダイアログと設定のシートに置く（提案からの追加には出さない）

- 日付: 2026-11-09
- 状態: 確定
- 対象: screens.md §2・§5・§9、docs/decisions/0039

## 決めたこと
- 0039 の「最初の書き込みの近くに、小さくリンクを出す」を、次の 2 か所にする（R6 で実装したとおり）
  - ＋の追加ダイアログ: この端末にアカウントがないときだけ、「追加すると、この端末用の保存場所が作られます」とプライバシーポリシーへのリンク（screens.md §2）
  - 設定のシート（⚙）の「データについて」: プライバシーポリシー・利用規約へのリンク。いつでも開ける（screens.md §9）
- 提案の［♡ やりたいリストに追加］（screens.md §5）からの初めての追加には、注記もリンクも出さない
- 初めて開いたときや、初めて追加するときに、同意を求めるモーダルは出さない（0039 のまま）

## 理由
- 目的は「知らせること」で、同意を取ることではない。使う目的をポリシーで公表していれば、集めること自体に同意は要らず、第三者にも渡さない（0039）
- ポリシーは設定のシートからいつでも開けるので、知りたい人は辿り着ける。提案の画面は眺めて ♡ を押すだけの軽い流れにしたい（0027）ので、注記を足さない
- 同意のモーダルは、最初の一歩を重くする（0039）。E2E のどのテストでも最初に閉じる手間も増える

## 影響
- 0039 の状態を「一部置き換え（リンクの置き場所。→ 0053）」にする
- 提案から追加した人は、ポリシーを見ないままアカウントができることがある。公開の 2 段目（0045）で知人に使ってもらい、気になる声があれば見直す
