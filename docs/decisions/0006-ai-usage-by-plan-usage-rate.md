# 0006 AI の使用量は、トークン量・費用ではなくプランの使用率で測る

- 日付: 2026-11-01
- 状態: 確定
- 対象: metrics.md §7、process.md §1

## 決めたこと
- metrics.md §7 の「トークン量（入力・出力）」と「費用」を「使用量」1 つにまとめる。測り方は、Claude の使用量表示（5 時間枠・週の使用率）をステップの開始時と PR マージ時に控えて、差を取る
- 途中で枠がリセットされたら差は出さず、「リセットあり」と書く

## 理由
- 定額プランで使っているので、`/cost` でトークン量や費用が表示されない。ステップ 1b の終了時に取れたのは、使用率（5 時間枠 54%・週 10%）だけだった
- 使用率にはほかの作業の分も含まれるが、ステップ同士を比べる目安としては使える

## 影響
metrics.md §7、process.md §1（ステップの開始時にも使用率を控える）、docs/metrics/ai-usage.md の列
