# 0015 予定日がある項目を一覧の上に日付順で並べ、カードに「あと何日」を出す（ステップ 5 の UX 改善）

- 日付: 2026-11-03
- 状態: 確定
- 対象: SPEC.md（版）、screens.md §2・§3、data.md §2、api.md §2、testing.md §2

## 決めたこと
- やりたいリストは、予定日が入っている項目を上に、予定日の早い順に並べる。その下に予定日がない項目を今までどおり `sort_order` の順に並べる。予定日が過ぎた項目も上に残す
- ドラッグでの並び替え（F9、まだ作っていない）は予定日がない項目だけにする
- 予定日を消したら、その項目は予定日がない項目の一番上に入る（`sort_order` を先頭にする）
- 同じ予定日の項目は、先に追加したもの（id の小さいもの）を上にする
- カードの予定日は 📅 をやめ、上に「あと 20 日」（当日は「今日」、次の日は「明日」、過ぎたら「3 日前」）、下に小さく年と曜日の入った「2026/11/23（月）」を出す
- 項目のシートの ✕ をやめる（パソコンでも外を押せば閉じる）

## 理由
- 予定日を決めた項目は「やる」と決めたもので、一覧を開いたときに真っ先に目に入るべき（ユーザーの希望）。近い順に並べれば、次に何をやるかがそのまま分かる
- 過ぎた項目を上に残すのは、やったにするか日を決め直すきっかけにするため。隠すとやり残したまま忘れる
- 予定日がある項目の順番は日付で決まるので、手で動かせるようにすると「動かしたのに戻る」ことになる。ドラッグは予定日がない項目の中だけにする
- 予定日を消した項目を元の位置に戻すと、長い一覧の下の方に消えて見失う。追加したときと同じく、予定日がない項目の一番上に入れる（画面の上での位置もほとんど変わらない）
- カードの表示は、このアプリが「思いつく → 残す → 眺める → やった 🎉」の流れで、予定日は楽しみに待つものなので、日付そのものより「あと何日」が先に目に入るようにした。日付は年・曜日まで出す（年が出ず来年の予定と見分けにくい、土日かどうかが大事、というユーザーの指摘）。📅 は「予定日」と分かる役目を「あと 20 日」が果たすのでやめた
- 同じ予定日の順番を `sort_order` にすると、画面（カードは `sort_order` を持たない）で予定日を変えたときにサーバーと並びが食い違い、読み直すと入れ替わる。画面でも分かる id の順にした。同じ日に複数を入れることは少なく、どちらが上でも困らない
- ✕ は、シートの外を押す・Esc で足りるので、パソコンでも置かない（ユーザーの判断）

## 影響
- 一覧の SQL の ORDER BY を変えた（`planned_on IS NULL, planned_on, CASE WHEN planned_on IS NULL THEN sort_order END, id`）。予定日がない項目同士の順番は変わらない
- PATCH で予定日を消すと `sort_order` も書き換える
