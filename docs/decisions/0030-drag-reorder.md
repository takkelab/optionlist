# 0030 ドラッグでの並び替えの見た目と、保存に失敗したとき

- 日付: 2026-11-07
- 状態: 仮決め（触って確かめる）
- 対象: screens.md §2

## 決めたこと
- 予定日があるカードには取っ手を出さないが、取っ手の幅（44px）だけ左を空け、上下のカードでタイトルの始まりをそろえる（ユーザーの判断）
- 並び替えは待たずに一覧へ出し、保存（`PUT /api/options/order`）に失敗したら「並び替えを保存できませんでした」をトーストで出して、一覧を読み直す
- 取っ手はキーボードでも動かせる（スペースで持ち上げ、上下の矢印で動かし、スペースで置く）。読み上げの文言は日本語にする

## 理由
- 予定日があるものとないもので左端がずれると、1 つの一覧に見えにくい
- 失敗の多くは、別の端末で完了・削除された項目を含んで 400 になる場合（0009）。手元の並びに戻すより、読み直して今の正しい一覧を出すほうがよい

## 影響
- dnd-kit（`@dnd-kit/core`・`@dnd-kit/sortable`）を入れた。横に動かさない modifier は自前で書き、`@dnd-kit/modifiers` は入れていない
- カードの外枠をボタンから `div` にし、中に取っ手のボタンとシートを開くボタンを並べた（ボタンの入れ子を避けるため）
- dnd-kit が読み上げ用に `role="status"` の要素を置くので、トーストに「お知らせ」という名前を付け、E2E はその名前で探す
