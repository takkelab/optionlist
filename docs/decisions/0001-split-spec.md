# 0001 SPEC を章ごとのファイルに分ける

- 日付: 2026-11-01
- 状態: 確定
- 対象: SPEC.md、docs/spec/

## 決めたこと
SPEC.md は入口（概要・スコープ・目次・未決事項）だけにし、各章を docs/spec/ の 7 ファイルに分ける。

## 理由
- メトリクスの章だけを上司のレビューに出せるようにするため
- 実装のセッションや reviewer エージェントが、必要な章だけ読めばよくなり、コンテキストを節約できるため（1 ファイルで 500 行を超えていた）

## 影響
章をまたぐ参照は「metrics.md §4」の形にした。reviewer エージェントと CLAUDE.md の参照先を更新した。
