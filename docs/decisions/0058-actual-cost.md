# 0058 実際の請求は 1 日 60 円ほど（月 1,800〜2,000 円）で、ほぼ Cloud SQL の固定の料金。月 3,000 円の上限は変えない

- 日付: 2026-11-11
- 状態: 確定（利用者が来てからの、使った分の料金は R11 の公開後に見直す）
- 対象: SPEC.md §1.3、metrics.md §5（月の費用）、docs/decisions/0035

## 決めたこと
- 0035 の見込み（月 2,000〜2,500 円）と上限（月 3,000 円）は変えない
- 今の請求は、ほぼ何もしなくてもかかる固定の料金として扱う。利用者が増えたときの料金（Cloud Run・Cloud Storage など）は、本番を公開したあと（0045 の 2 段目以降）に実額を見て、新しい記録にする
- 今は Google Cloud の無料トライアルのクレジット（47,462 円）で払っている。トライアルは 2027-02-08 に終わり、有料のアカウントに切り替えないとリソースが止まる。使い続けるなら、それより前に切り替える。予算のアラート（50・90・100%。0042）は、切り替えた後の請求で鳴ることを確かめる

## 理由
- 請求は、`takkelab-pg`（Cloud SQL。db-f1-micro・Enterprise・東京・ストレージ 10GB）を作った 2026-11-09 から始まった。1 日半ほどで 95 円、1 日あたり 60 円ほどで、月にすると 1,800〜2,000 円
- 確認用・本番とも、Cloud Run は最小 0 台で、触るのは自分だけなので、使った分の料金はほぼ出ない。金額は 0035 の Cloud SQL の見込み（月 1,800〜2,200 円）とおおむね合う
- 確認用のデータを増やしたり、意識して使ったりしても、固定の料金は変わらない。ひとりで使っても、利用者が増えたときの料金は分からないので、確かめるのは公開の後にする
- SKU ごとの内訳までは見ていない。合計が見込みの中に収まっているので、今はこの粒度で足りる

## 影響
- トライアルが終わるまで（あと 89 日ほど）の見込みは 5,000〜5,500 円で、クレジットの 1 割強
- 0035 の状態を「確定（実額は 0058）」にした
