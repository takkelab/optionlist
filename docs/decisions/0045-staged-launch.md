# 0045 公開は「自分だけで 2 週間 → 知人数人 → 一般公開」の 3 段階で進める

- 日付: 2026-11-08
- 状態: 確定
- 対象: SPEC.md §3、process.md §5（R11）

## 決めたこと
1. **自分だけ（2 週間）**: 本番に出し、自分の日常で使う。削除のジョブ・バックアップの書き出し・アラートが実際に動いたこと（ログとメールが届いたこと）を確かめる。復旧の訓練（0041）を 1 回行う
2. **知人数人**: 想定ユーザーに近い人に URL を渡す。iPhone（Safari とホーム画面に追加したアプリ）と Android（Chrome）の実機で、次を確かめる: 最初の追加でアカウントができる、ホーム画面に追加したときに同じアカウントのまま使えるか（使えなければ復旧コードで移れる）、復旧コードで別の端末に移ると古い端末が切れる、すべてのデータを消せる
3. **一般公開**: `noindex` を外し、URL を広く出す
- 2 まで終わるまでは、すべてのページに `<meta name="robots" content="noindex">` と `X-Robots-Tag: noindex` を付ける

## 理由
- 本番でしか起きない問題を、他人のデータがある状態で初めて踏まないため
- iOS のホーム画面に追加したアプリと Safari が Cookie を共有するかは、iOS のバージョンによって違い、自動のテストでは確かめられない（0032・0033）

## 影響
- 結果は `docs/ops/launch-checklist.md` に書き、R11 の PR で残す
- 2 で、ホーム画面に追加すると別のアカウントになると分かったら、ホーム画面に追加する前に復旧コードを控えるよう、画面で案内する（screens.md §9 を直し、新しい記録にする）
