# 決定の記録（decisions）

仕様の「なぜそうしたか」を残す場所。今の仕様そのものは SPEC.md と docs/spec/ に書く（process.md §3）。

## ルール
- 1 件 1 ファイル。ファイル名は `NNNN-短い説明.md`（例: `0003-perf-target-relaxed.md`）。番号は連番で、使い回さない
- 数行でよい。長い議論は書かず、結論と理由と根拠の数字だけ書く
- 一度書いた記録は書き換えない。判断を変えるときは新しい記録を作り、古い記録の「状態」を「置き換え済み（→ NNNN）」にする
- SPEC の修正と同じ PR で追加する

## テンプレート

```markdown
# NNNN タイトル

- 日付: YYYY-MM-DD
- 状態: 確定 / 置き換え済み（→ NNNN）
- 対象: metrics.md §4（SPEC のどこに関係するか）

## 決めたこと
（1〜3 行）

## 理由
（計測値やデータがあれば数字で書く）

## 影響
（変えたファイル、目標値、ルールなど）
```
