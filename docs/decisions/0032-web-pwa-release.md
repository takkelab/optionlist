# 0032 一般向けには Web＋PWA で出し、ストアは後で考える

- 日付: 2026-11-08
- 状態: 確定（ストアに出すかは公開後に決める）
- 対象: SPEC.md §1.2・§2、architecture.md §1、screens.md §10、process.md §5

## 決めたこと
- 独自ドメインの Web アプリとして出し、PWA（manifest・アイコン・Service Worker）にしてホーム画面に追加できるようにする
- Service Worker が保存するのは画面の殻（ビルドした JS・CSS・アイコン）だけにする。`/api` の応答はキャッシュしない
- App Store・Google Play への配布はしない（SPEC.md §2.2）

## 理由
- 費用はドメイン代（年 1,500〜3,000 円）だけで、URL を開けばすぐ使える。ストアは Apple に年 $99、Google に $25 かかるうえ、審査が要る。開発機が Windows なので、iOS のビルドには Mac かクラウドのビルドサービスも要る
- ストアに出すなら、アプリ内でのアカウント削除（0039 の「すべてのデータを消す」で満たせる）が要る。Web を包んだだけのアプリは審査の 4.2（機能が少ない）で落ちることもある。まず Web で使われるかを確かめる
- `/api` をキャッシュしないのは、共有の端末に他人のリストを残さないため。また、古い一覧から並び替えを送ると 0030 の読み直しが増えるため

## 影響
- iOS は「共有 → ホーム画面に追加」を自分でやってもらう必要がある。ホーム画面に追加したアプリが Safari と Cookie を共有するかは iOS のバージョンによるので、公開前に実機で確かめる（0045、SPEC.md §3）
- 公開するまでは `noindex` にする（0045）
