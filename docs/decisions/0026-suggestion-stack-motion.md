# 0026 提案の画面は、進むと右から入り、［‹］で戻ると左から戻る。追加のボタンは押している間だけ濃くする

- 日付: 2026-11-05
- 状態: 仮決め（速さ・ずれの量は触って調整する）
- 対象: screens.md §1・§5、SPEC.md（版）

## 決めたこと
- 提案の画面（探す画面 → 提案 1 件 → 関連・タグ・テーマ …）で、アプリのリンクを押して進むと、次の画面が右から重なって入り、今の画面は少し（30%）だけ左へずれる。ヘッダーの［‹］で戻ると、その逆（今の画面が右へ抜け、前の画面が少し左から戻る）。上に重なる画面の左の辺には薄い影を付ける。長さは「やりたいこと｜やったこと」の切り替えと同じ 0.25 秒
- ブラウザの戻る・進む（iPhone の端からのスワイプ、Android の戻るジェスチャー、PC の戻るボタン）では動かさない
- タブの切り替え（やりたい・提案）では動かさない
- 視差効果を減らす設定と、View Transitions が使えないブラウザでは、今までどおりすぐ切り替える
- [♡ やりたいリストに追加] は、押している間だけ色を一段変え、少し（97%）縮める（ボタンの色は 0027 で白地に枠・追加後は塗りに変えた。押す前は薄いティール、塗った後は濃いティールにする）

## 理由
- ユーザーから「多くのアプリは、開くと右から出てきて、戻ると左から戻ってくる。今の形が最適か」と声があった。今の提案の画面は動きがなく、関連から次の提案へ移っても中身が入れ替わっただけに見え、「1 つ奥へ進んだ」ことが伝わらなかった
- 右から入る形は、左から右へ読む文化で「右＝先・奥」という空間のたとえに合い、iOS のナビゲーションと Material Design（shared axis X）の標準なので説明が要らない。提案の画面は「たどってきた道を戻る」作り（0020）で、階層を進む・戻るを表す横の動きがいちばん合う。シートは下から（一時的に重ねる）、同じ階層のタブは動かさない、という使い分けにもそろう
- 全幅で押し出す形（0019 の切り替え）ではなく、下の画面を少しだけずらして上に重ねる形（iOS と同じ）にした。0019 は「横に並んだ 2 つのリストの切り替え」なので並びどおりに全幅で動かすが、こちらは「上に積む」階層なので、重なりで表す
- ブラウザの戻るで動かさないのは、iPhone の Safari が端からのスワイプで戻るとき、自分で前の画面を滑らせて見せるため。そのあとアプリも動かすと二重に動いて見える。ブラウザの戻るとアプリの［‹］は、どちらも履歴を戻る（popstate）ので、動かすのはアプリのリンクと［‹］を押したときだけにした
- 押している間に色を変えるのは、ユーザーの要望。一覧の「＋」・🎉・カードはすでに押している間に濃くなるが、追加のボタンだけ変わらず、押せたのかが分かりにくかった。色だけだと親指の下に隠れて見えないことがあるので、少し縮める動きも足した

## 影響
- `lib/PageSlide.ts` の待つ相手を、一覧の印（`data-list-ready`）に決め打ちせず、呼ぶ側が渡す形にした（`slide(side, update, readySelector)`）。「やりたいこと｜やったこと」の切り替えは今までどおり一覧の印を待つ
- 提案の画面は、中身を描き終えた要素に `data-suggestion-page`（値は履歴の項目の key）を付ける。進む・戻るでは、今の画面と違う key の印が出るまで（最長 0.3 秒）待ってから後の見た目を撮る。［‹］は `navigate(-1)` で、画面が入れ替わるのは popstate のあとなので、すぐ描き終わる `flushSync` では待てないため。戻ったときのスクロール位置は、印を付けるのと同じ描画で戻すので、戻した位置で撮れる
- 提案の画面へのリンクは `StackLink`、戻るボタンは `useStackSlide` を通す。新しいタブで開くなどの修飾キー付きのクリックは動かさない
- ヘッダー・タブバーは今までどおり名前を付けて別に撮るので、画面と一緒には滑らない（ヘッダーの文字は薄く入れ替わる）。下に固定した追加ボタンは画面と一緒に滑る
- トークンに `--shadow-stack`（重なる画面の影）を足した
- 押している間の色だけでは足りず、ユーザーから「X のいいねのような分かりやすいエフェクトがほしい」と声があったので、押したときの弾みと粒は 0027 で決めた
- E2E: 進むと右から入り、［‹］で戻ると左から戻ってスクロール位置も戻ること、ブラウザの戻ると視差効果を減らす設定では動かさないこと（suggestion-motion.spec.ts）
